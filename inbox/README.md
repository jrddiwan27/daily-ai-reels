# 📥 JDS Video Reverse-Engineering Inbox

Drop any video file or link here to automatically reverse-engineer and recreate it in Jayant Digital Studio's high-converting style.

### Option 1: Drop Video Files
- Put any video file (`.mp4`, `.mov`, `.webm`, `.mkv`) into `inbox/videos/`.

### Option 2: Paste Social Media Links
- Add YouTube Shorts, Instagram Reels, X videos, or TikTok URLs into `inbox/urls.txt`.
- The engine uses `yt-dlp` to download the video automatically.

### What the Engine Does:
1. **Frame-by-frame extraction**: Extracts keyframes at scene transitions.
2. **Multimodal AI Deconstruction**: Uses Gemini Flash to extract the psychological hook formula, screen layout, motion graphics motifs, color palette, and word-by-word pacing.
3. **Recreation**: Recreates a fresh, 100% original script and full-screen motion design on breaking AI topics (e.g., Qwen-Image, DeepSeek, local LLM stacks) matching that viral structure.
4. **Autonomous Voice & Render**: Synthesizes broadcast audio, compiles HyperFrames composition, and attaches rotating face CTA.
